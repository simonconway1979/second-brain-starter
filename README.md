# Second brain starter

A folder that sets up a personal second brain with Claude Code or Codex, built on your own files. You add files, and the AI keeps a wiki from them.

The method is Andrej Karpathy's [LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f). This folder adds fixed rules, so every page links back to the file it came from.

**To start:** download this folder, then open [START-HERE.md](START-HERE.md).

**Sample files:** `setup/sample-files/` holds documents from Rehanga, a made-up company. All of it is fictional, including the people.
